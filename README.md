# 👋 Olá, eu sou o Vagner Ventura!

Backend Engineer especializado em Java, Arquitetura de Microsserviços e Sistemas Distribuídos, com atuação em projetos corporativos dos setores financeiro e saúde.

Atualmente trabalho no desenvolvimento e evolução de soluções para o mercado financeiro, participando da modernização de plataformas de pagamentos, processamento de eventos financeiros e integrações entre sistemas críticos utilizando Java, Spring Boot, Apache Kafka e Microsoft Azure.

Tenho experiência na construção de aplicações cloud-native com foco em escalabilidade, resiliência, observabilidade, segurança e qualidade técnica, aplicando Arquitetura Hexagonal, DDD, SOLID, Clean Architecture e boas práticas de engenharia de software.
