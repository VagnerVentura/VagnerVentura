# 👋 Olá, eu sou o Vagner Ventura!

Desenvolvedor Backend Java, formado em Desenvolvimento de Software Multiplataforma pela FATEC, com experiência no desenvolvimento e evolução de sistemas corporativos de média e grande escala.

Atualmente atuo na construção de APIs REST com Spring Boot em uma arquitetura de microsserviços, participando de integrações entre sistemas e processamento de grandes volumes de dados, incluindo bases com milhões de registros.

Tenho forte atuação na organização de aplicações em camadas, aplicando boas práticas como SOLID e Clean Code, com foco em escalabilidade, performance e manutenção de sistemas.

No dia a dia, trabalho com:

- Refatoração de código legado e evolução de sistemas
- Segurança com OAuth2/OIDC (Keycloak)
- Versionamento com GitLab e pipelines CI/CD (Jenkins e Argo CD)
- Conteinerização com Docker

Busco evoluir continuamente como desenvolvedor backend, contribuindo com soluções robustas e alinhadas às necessidades de negócio.

## 📌 Projetos em destaque

### App LaMusic (Spring Boot & React)
Aplicação full stack para gerenciamento de um e-commerce de instrumentos musicais.

- **Backend:** Spring Boot, Spring Data JPA, MySQL, REST API, segurança com JWT.
- **Frontend Web:** React, Axios, React Router, integração com backend via REST.
- **Mobile:** React Native (aplicativo multiplataforma), consumindo APIs criadas no backend.
- **Funcionalidades:** cadastro de usuários, autenticação, gerenciamento de produtos, carrinho de compras e pedidos.
- **Docker:** uso de Docker Compose para facilitar o deploy do ambiente.

### Livraria Backend
API REST para controle de acervo e estoque de livros.

- **Backend:** Java, Spring Boot, Spring Data JPA, MySQL.
- **Endpoints:** cadastro de livros, autores e categorias.
- **Boas práticas:** uso de DTOs, mapeamento com ModelMapper, e arquitetura em camadas (controller, service, repository).

### API Farmácia Hospitalar
Sistema para controle de estoque hospitalar.

- **Backend:** Spring Boot, Spring Data JPA, MySQL.
- **Entidades:** Paciente, Prescrição, Medicamento, Dispensação.
- **Relacionamentos:** modelados com JPA (OneToMany, ManyToOne).
- **Funcionalidades:** registro e controle de medicamentos prescritos e dispensados.
- **Diferencial:** foco em lógica de negócio e integridade dos dados.

### Agregador de Investimentos
API para consolidação de dados financeiros.

- **Backend:** Spring Boot, Spring Data JPA.
- **Endpoints:** registrar, listar e consultar investimentos por tipo.
- **Estrutura:** modular e preparada para integrações externas.
- **Extras:** possível uso de schedulers para atualização periódica.

### Desafios Spring Boot
Micro-serviços REST simulando requisitos reais de mercado.

- **Destaques:** validação, uso de DTOs, tratamento de exceções e lógica de negócio inspirada em cenários reais.
